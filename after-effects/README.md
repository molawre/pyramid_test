# The 5 levels of healing: After Effects rebuild

В пакете две схемы:
- `five-levels-ae.jsx`: System model, исходная пирамида-стек;
- `poles/five-levels-poles-ae.jsx`: Polarity model, двойная пирамида со светлым северным и тёмным южным полюсом.

Обе собираются одинаково, шрифты общие (`fonts/`).

`five-levels-ae.jsx` собирает в After Effects композицию 3840×2160 (30 fps, 10 s), которая
повторяет `brand/five-levels-navy.png` один в один.

## Запуск

1. Установи все шрифты из папки `fonts/` (двойной клик → Install).
   Это статические срезы DM Sans и Newsreader (OFL) с тем же оптическим размером (`opsz`),
   с которым рендерился PNG. Стандартные DM Sans и Newsreader в AE доступны только с opsz 14/18,
   и у них другие ширины букв.
2. Если нужен заголовок шрифтом брендбука, установи Kalice (Light и Bold, коммерческий шрифт бренда).
   Без Kalice скрипт возьмёт Newsreader Op72, как на утверждённой картинке.
   Переключатель `USE_KALICE` находится в начале скрипта.
3. After Effects → File → Scripts → Run Script File… → `five-levels-ae.jsx`.
   Держи `five-levels-navy-reference.png` рядом со скриптом.

## Что получится

- **Shape-слои**: каждая пластина (`Plate 01…05`, внутри группы `Top face` / `Left side` / `Right side`,
  у пятой ещё `Grid line 01…18`), выноски, точки, ось, засечки, скобки, сетка фона, тень, линия футера.
  Якорь каждого слоя стоит в центре его объекта, так что анимировать удобно.
- **Текстовые слои** (point text, всё редактируется): eyebrow, заголовок (в AE 2024.3+ одним слоем,
  слово *healing* выделено жирным начертанием), номер / название / код / описание каждого уровня,
  подписи оси и скобок, футер. Якорь стоит на базовой линии первой строки.
- **Фон**: Navy `#023866` и две «атмосферы» фирменного градиента (sky haze и gold base):
  цветной солид через радиальный luma-матт (Gradient Ramp).
- **Гайд**: `REFERENCE — approved PNG (guide)` лежит сверху. Он скрыт и в рендер не попадает,
  включи глаз, чтобы сверить.

## Стиль (брендбук Dietrich Klinghardt 2026)

Navy `#023866`, Teal `#1E9DA1`, Cool Gray `#F1F4F4`, Gold `#F79B09` (только точки-акценты).
Заголовок Kalice Light, sentence case, жирным выделено одно слово. Подзаголовки DM Sans Bold,
текст DM Sans Regular, служебные подписи DM Sans Medium капсом с трекингом 140.

## Polarity model (`poles/`)

Физический слой (01) стоит в середине. Уровни 02–05 сужаются вверх к светлому полюсу (север / свет) и
зеркально вниз к тёмному (юг / тень). Южная половина — точное зеркальное отражение северной: толщина
её пластин смотрит вверх. Слои названы `Plate 0X … — north` / `— south`, подписи `North 0X` / `South 0X`,
у каждого слоя свои выноски и точки. Фон — Navy и три свечения: светлое небо над севером, голубая дымка
и глубокая тень под югом. Референс для сверки — `poles/five-levels-poles-reference.png`.
