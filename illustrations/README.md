# Light emission illustrations: clean vs. disturbed layers

Brief from Dr. Klinghardt: light leaves the body in thin layers. A healthy organ (e.g. the heart)
emits clean, even layers; an organ with illness emits disturbed, darker layers.
The inspiration images (biophoton imaging, Kirlian/aura charts, Popp) were used only to understand
the mechanics of the glow, not as visual references.
